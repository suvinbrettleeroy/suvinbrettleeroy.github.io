## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS)
- npm

### Clone the Repository

```bash
git clone https://github.com/your-username/Suvin_Portfolio.git
```

### Navigate to the Project

```bash
cd Suvin_Portfolio
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
